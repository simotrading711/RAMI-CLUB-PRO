# RAMI CLUB PRO — نسخة Android أولية

## الموجود حالياً
- مشروع Android أصلي بلغة Java.
- واجهة عربية بتصميم أسود وذهبي.
- اختيار رامي 13 ورقة أو 14 ورقة.
- طاولة تدريب محلية أولية وسحب/إنهاء دور تجريبي.
- محفظة نقاط افتراضية فقط.
- GitHub Actions لبناء APK تجريبي.

## غير المنفذ بعد
هذه ليست لعبة مكتملة أو متعددة اللاعبين. لا يوجد خادم، تسجيل حسابات، غرف عبر الإنترنت، مزامنة، أو نظام دفع. يجب تطوير قواعد الرامي والتحقق منها واختبارها قبل النشر.

## البناء من الهاتف عبر GitHub
1. أنشئ مستودع GitHub جديداً أو استخدم مستودعاً مخصصاً لهذا المشروع.
2. ارفع محتويات هذا المجلد كما هي إلى جذر المستودع.
3. افتح تبويب Actions.
4. اختر Build RAMI CLUB PRO APK ثم Run workflow.
5. بعد نجاح البناء افتح نتيجة التشغيل ونزّل artifact باسم RAMI-CLUB-PRO-debug-apk.

## تنبيه قانوني ومالي
النسخة الحالية تستخدم نقاطاً افتراضية غير قابلة للبيع أو السحب. لا تضف إيداعات أو رهانات أو سحوبات بأموال حقيقية إلا بعد الحصول على المشورة القانونية والتراخيص اللازمة في البلدان المستهدفة، مع التحقق من متطلبات العمر ومكافحة الاحتيال وحماية المستخدمين.
